## Goals / Non-Goals

**Goals:**

- 对完整站立牌面评价，区分直接进张与同向听改良；数值受牌河、副露、手牌和财神约束。
- 在最低向听候选内部允许后续收益改变原始进张排序，解释边张/嵌张、复合形和对子用途。
- 弃牌、PASS、吃碰后弃牌使用同一评价语义，并在有限预算内确定性地完成或退回完整结果。
- 提供可复核的证据、版本与成对评估，达标后再启用新默认。

**Non-Goals:**

- 修改 shanten 定义、HU/财飘规则、KONG 决策、抓打圈、吃两摊限制或平台合法动作协议。
- 修复窗口身份、请求调度、网络延迟、动作重试；不以静态评分修复 C/D。
- 完整对手隐手推断、MCTS、无界 rollout、训练模型或重新生成 teacher 数据。
- 把未知牌数量说成真实墙内数量，把结构启发分说成已校准胜率。

## Decisions

### 1. 评价输入是受本家视角限制的不可变状态

预计在 `mj/hand_eval.py` 定义 `EvalContext` / `HandEvaluation`，由 `mj/bot.py` 适配既有 `(g, seat) -> action` 接口。评价输入只包括本家手牌、四家公开牌河/副露、规则开关、抓打圈、吃牌额度、剩余活墙、当前阶段和已知摸牌/杠摸上下文，不读取 `Game.wall` 的牌值或对手暗手；离线引擎有这些信息也不得使用。

站立暗牌张数为 `13 - 3 * locked`。自摸或吃碰后待弃牌为多一张；先枚举该状态下的合法弃牌，保留最低向听，再在同向听内执行财神保护。HU/财飘和 KONG 分支按原语义处理后才进入新弃牌/吃碰评价。

`visible[t]` 包含本家手牌、四家当前牌河和全部副露；已被吃碰移走的河牌不能与副露重复扣除。`remaining[t] = max(0, 4 - visible[t])` 是未见数量，`N = sum(remaining)` 是未知池大小，不等于活墙长度。计数超过 4 视为诊断异常，不靠截零掩盖无效输入。

一次假想摸牌 t 后同时执行 `hand[t] += 1`、`visible[t] += 1`；后续弃牌是已见牌转移，可见总量不变。吃碰前后复用相同可见计数，既有 spec 的快照不变量保持成立。

### 2. 整手分解保存用途与互斥关系

枚举可实现的标准形和未副露时的七对分解。每个分解分配真实牌与财神给面子、雀头、候选搭子和剩余单张，分配数不得超过输入数量；面子/搭子名额不超过剩余成牌需求。先以既有 shanten 确定最优分支，再在同向听分解间评价结构。

- `1234` 允许 `123 + 4` 与 `1 + 234` 等替代分解，不能算作两个同时完成的面子。
- `889` 允许对子与 89 搭子竞争用途，不能把同一张 8 同时贡献两份完成收益。
- 两面、嵌张、边张的直接补全集合分别按实际未见数计量；不只按类型固定排名。
- 对子作为雀头的价值与作为可碰面子的价值分开。缺雀头、已有替代雀头、对子过剩、七对分支领先会产生不同边际价值。
- 天然对子才有碰牌潜力；财神补成的逻辑对子不产生非法 PONG。外部同种牌耗尽时碰牌潜力为零，但雀头或七对价值仍可存在。

结构特征 `B` 和公开可兑现的吃碰潜力 `C` 归一化至 [0,1]。`B` 的计算保存最佳分解及各项贡献；复合形的灵活性由替代分解/后续模拟体现，不把互斥方案的牌数或进张直接相加。`C` 依据未见同牌数、当前吃碰资格、剩余面子名额和雀头替代性，不等价于对手出牌概率。抓打圈、财神禁碰和吃两摊上限在该特征中同样有效。

首版采用以下可复算定义，不把 B/C 留给实现者临时选常数。对达到当前最低向听的一个分解 D，令 `K=4-locked`、`m` 为已完成暗面子数、`h` 为是否已有分配了材料的雀头（0/1）。每个占用面子名额的未完成搭子 b，其 `a(b)=min(1,有效补成牌的未见数之和/8)`，包含财神补成时仍按实际材料核对。标准形 `B(D)=(2*m+h+sum a(b))/(2*K+1)`；七对分支 `B(D)=已完成对子数/7`。对子作雀头后不再贡献搭子分；各分支的差异是需消融验证的结构启发，不解释为胡牌概率。

标准形 `C(D)` 对未占雀头且可用于副露的天然对子计 `remaining[t]/2`，对可以从上家吃成的天然搭子计 `a(b)`；吃搭子只取不超过 `2-chows` 个且不超过剩余面子名额的组，再将上述和除以 `max(1,K-m)` 并限制至 [0,1]。冻结反应、财神参与的非天然组不计入 C；七对分支的 C=0，不把退出七对后的副露收益混入该分解。B 与 C 必须来自同一个 D：选择使 `wB*B(D)+wC*C(D)` 最大的可行分解，不能分别取两项最大值再组合。

仅换一组邻接常数的方案成本较低，但无法处理复合形重叠和财神用途；本次选用显式分解。若分解数量超出预算，整次比较降级，不能按牌编码截掉方案。

### 3. 直接进张与改良进张使用不同字段

`U1` 是降低当前向听的有效未见张数；听牌时改为本规则/摸牌上下文下的合法和牌张数。`p1 = U1 / N`，`N=0` 时定义为 0。

对每种 `remaining[t] > 0` 的下一张牌，模拟摸牌并按非递归基础评价选择最佳合法弃牌，得到子站立状态 `x_t`。相同向听的改良量定义为：

```text
p_hold(t) = 原手 x 在 visible+t 下的有效进张数 / (N-1)
I = sum_t remaining[t] / N
        * 1[shanten(x_t) == shanten(x)]
        * max(0, p1(x_t) - p_hold(t))
```

另记录满足改良条件的牌种、未见数及对应弃牌。已降向听的子节点不再计入 I，避免把同一进展重复称为改良；不同向听的 ukeire 不直接求平均比较。子状态与“摸 t 后仍保留原手”的基准使用同一份更新后的 visible 和 N-1，避免单纯未知池变小被误判为好型改良；N≤1 时 I=0。第一摸合法 HU 的终态不计算 I。

例如 `13` 摸 4 可转为 `34` 两面；若相关 4 已全部可见，这条改良贡献必须为零。A 的 `68` 与 `89` 必须结合全手及只剩一张的 5w 计算，不能把通用牌谱口号当成收益。

### 4. 前瞻深度与评分是显式配置

采用“枚举下一张摸牌 + 最佳弃牌 + 听牌叶子的下一摸和牌集合”的浅层方法。它能得到 `H2`：在所声明的后续弃牌策略下，两次自摸以内的模型和牌概率。第一摸合法胡计入终态；否则仅对下一站立牌面的合法听口累计第二摸概率。活墙/抓打圈/规则门禁不支持的假想动作或摸牌机会不能计分。普通 future draw 不能伪造为 kong draw 绕过有财必拷响门禁。

未知池采用无放回模型，记录 `model_assumption=uniform_unseen_no_opponent_actions`；不使用真实墙序，也不宣称该模型包含他家抢先自摸或出牌分布。H2 模型遇合法 HU 即作为终态，表示该模型下获得并接受和牌机会的概率；它不模拟实际财飘继续打牌的收益，也不改变线上的财飘决策。非胡分支的名义后续策略是非递归基础评价 Q0，不在子节点递归调用完整 Q，避免隐藏的搜索爆炸。

同最低向听、同财神保护档的候选采用：

```text
Q0 = p1 + wB * B + wC * C
Q  = p1 + wI * I + wH * H2 + wB * B + wC * C
排序：Q 更高 → 已声明的稳定结构/喂牌次序 → 稳定动作编号
```

所有特征非负、尺度与缺失状态明确；未完成的 I/H2 不得当零进入与完整 Q 的比较。基础层、前瞻层各自是一套完整候选结果。

权重按被评价站立牌面的向听档（0 / 1 / ≥2）和活墙档（≤8 / 9–24 / ≥25）选取，同向听、同活墙档的 PASS 与 claim 必须使用相同系数；不同向听先由硬约束决定，不跨档比较 Q。子节点按自身站立牌面选档，不依赖它来自吃碰还是普通弃牌、也不依赖遍历顺序。听牌状态优先用合法听口及 H2；雀头/复合形的静态奖励不能让 bot 退听。七对/爆头的当前可实现分支由规则入口确认，并写入解释；本版不增加未经校准的潜在倍率期望项，HU/财飘行为沿用原逻辑。

实现先使用显式种子配置 `wI=0.25, wH=0.5, wB=0.05, wC=0.025` 做诊断，三个向听档最初共用这组值。它们不是最优性结论。校准限定网格：`wI ∈ {0,0.25,0.5}`、`wH ∈ {0,0.5,1}`、`wB ∈ {0,0.05,0.1}`、`wC ∈ {0,0.025,0.05}`；先全局消融，只有独立验证支持时才分档。配置、分解特征定义及归一化方式共同参与指纹；不能只记录一个 BOT 名称。

完整多步搜索能进一步表达长期收益，但难满足当前反应窗预算；本次不采用。仅看两摸模型也不足以穷尽 A 的改良，故保留同向听 I 与可解释结构 B。

### 5. PASS 与吃碰后状态使用同口径收益

PASS 保留原始站立暗牌，不将 pending 牌加入手牌。每个合法吃碰选项移除消耗牌、增加一组副露、枚举立即弃牌，与 PASS 在同评价层级比较：

- 向听降低：按既有原则优先接受，再以完整的共享评价在同向听动作中择优。
- 向听升高：拒绝。
- 向听相同：要求 `Q_claim - Q_pass >= tau[action]`。初值为 `tau[PONG]=2/N`、`tau[CHOW]=4/N`，与旧 ukeire 门槛在 p1 尺度上对应；校准只在预先声明的乘数 `{0,0.5,1,2}` 中选择。

同向听且 N=0 时直接 PASS，不能因分母为零或将阈值设零而接受副露。

需分别传递副露后的 chows、七对资格、天然对子数量及剩余面子数，不能只改 locked。弃牌预选结果与真实吃碰后弃牌在相同状态、配置、评价层级下必须一致。KONG_OPEN 同窗继续走既有整窗 legacy 逻辑。

已有明确可碰动作的 Q 评价和“对子未来可能被碰”的 C 是不同事实。C 不使用凭空设定的对手出牌概率；从不同弃牌者处吃碰的真实回合速度差异，本版仅记录 owner/turn 与模型限制，不给未经验证的速度奖励。该限制必须在评估报告中保留，不能称为完整回合期望模型。

### 6. 按完整层级提交结果，防止部分搜索偏向

先得到所有最低向听合法候选的 legacy 结果，然后完成所有候选的 Q0，最后尝试所有候选的 Q。首版不按牌编码或未经证明的静态 top-K 删除候选；基于可证明上界的剪枝必须另有全量差分。

节点上限与单调时钟预算共同限制计算。实现种子上限为弃牌 4096 / 反应 2048 个展开状态；shape-v1 profile 内部预算为弃牌 17.5ms / 反应 7ms，为 20ms / 10ms 的外部验收限额保留动作调用余量。弃牌前瞻将 Q0 结果、决策内基础特征和重复的下一摸/最佳弃牌状态复用，并把非财神批量热点放入 Rust；未来分支只在需要解释时回填子牌进张，profile 指纹计算按不可变参数缓存。这些优化不改变候选层级或评分公式。Q 阶段可按 `I/H2∈[0,1]` 的保守上界先评估高上界候选；严格低于已完成 Q 的候选显式记录为 `q_pruned`，不得以静态牌号或未经证明的 top-K 删除。节点是进入一次分解或假想状态评价的逻辑工作单元，缓存命中也计数，以保持冷热缓存下的节点上限语义。原始内核调用量另计。检查发生在每次展开前；单个内核调用不可抢占，超额耗时必须记录，不能称为硬实时保证。

预算用于整次决定，包括 PASS 和全部吃碰候选，不是每个分支分别享有一份。耗尽时回退到最近完成的全候选层级；若 Q0 未全量完成则回退 legacy，禁止用某些候选 Q 和另一些候选 Q0/缺失值混合排名。固定节点预算、不触发时钟兜底时，改变候选枚举次序不得改变结果。

调用方如果已提供有效计算截止，只能缩小评价预算，不改变动作提交边界或授权条件。无截止时使用 profile 上限。解释输出不能触发第二次搜索；所有缓存按手牌、locked、visible、规则/阶段/吃牌资格、profile 和评价层级区分，容量有界，不能在一个可变全局变量保存“最近一次解释”供十场线程共用。

### 7. 解释记录与动作生命周期分离

`decision` 附加可选 `evaluation` 对象，包含版本/配置指纹、实际层级、候选总数、选中理由、原始特征及加权贡献、直接/改良牌集合、最佳弃牌、模型假设、节点/内核调用/耗时和回退原因。普通实时记录只保留选中项、legacy 最优项及至多另外三项；离线可输出全候选，两个模式不得改变选择。

没有对某窗调用策略就没有策略 decision。C 的重算结果只能放在离线 `counterfactual_evaluation` 中，并显式关联原窗口，不能补造线上 PASS/PONG；D 保留 `server_auto_discard` 证据。沿用 gid + decision id 关联 action，反应决策继续关联已有 WindowAttemptKey；缺身份按现有弱证据语义处理。

增加 `--bot-evaluator legacy|shape-v1`（只影响 strategy=bot）及 profile 元信息，离线评估与线上运行选择相同实现。旧日志无字段显示 `legacy_unrecorded`，不推断权重。诊断只含本家可见信息，不含令牌或他家暗手。

### 8. 验收先固定行为边界，再验证整体收益

实施时从上述日志提取最小可公开 fixture：手牌、公开可见计数、规则与动作阶段、来源 seq/decision id 和证据分类。fixture 不依赖运行者拥有 `local/` 日志；缺失信息显式记录，不从后续事件补给策略。牌河不足以完整重建时不填造未见数。

固定测试覆盖 A–E 的旧结果与归因。新评价要求 A 的完整解释区分 68/89 改良，合成等可见变体中保留更可改良结构；B/E 不硬编码用户建议动作，若推翻旧选择必须有完成的同层级评分依据。C 在可合法决策的快照模型下仍选择碰；D 的可决策牌面仍优先切 4w，同时原日志保留代打归因。

性质与变体覆盖：花色置换不引入编码偏向、相同候选集合置换、复合形材料守恒、对手隐藏信息不影响结果、已见数单调扣减、摸牌模拟不双扣、天然/财神对子、七对与副露互斥、YCBK、抓打圈、吃额度、墙尾、预算中断及并发解释串扰。若添加 Rust 热点，先与 Python 规范实现做随机及定向差分。

离线校准集、验证集、最终测试集的种子与对手版本提前固定且互不重叠；不能用这五个案例代替独立测试集。对手必须绑定冻结 legacy callable，避免把 `True=当前 BOT` 当成固定对手。相同种子与座位/庄家安排分别运行新旧玩家，全部 16 个组合均衡。

发布闸门：

- 全量 `tests/`、相关差分、OpenSpec strict 校验和 diff 检查通过。
- 最终留出集至少 4096 个成对牌局，报告平均得分差、自摸率差、倍率和流局；按种子分组的成对 bootstrap 95% 区间，得分差下界 >0，且自摸率差下界 ≥-1 个百分点。无确定收益则不切默认；任何扩样规则须在看测试结果前固定，不边看边挑终点。
- 冻结同机同内核，交错各 3 次 200 局对比，总 elapsed/games 中位数增加 ≤15%；10 场并发下分别报告 discard/react 的 p50/p95/p99/max、节点与回退率。额外评价 p95 分别 ≤20ms / 10ms，包含解释开销；时钟超额和回退不能省略。
- 校准参数冻结后，显式使用 BOT / shape-v1 / SSE + incremental state / 15/s，完成至少 3 个串行新房、每房 10 场。逐窗报告 strategy PASS、身份未确认、未提交、超时代打及实际 POST，不能用零 409 或零 auto_played 代替窗口审计。要求无非法动作、重复旧 POST、解释关联错误以及有明确证据归因于新增评价耗时的窗口损失；身份协议与 HTTP 遗留问题单列。

在线新房不用于重新调权重；房间/对手不同，不能把单房胜率差当因果证明。

## Risks / Trade-offs

- [把牌型美观当胜率] → 原始 U1、I、H2、B/C 各自可见；B/E 保留反例，以独立成对得分验证。
- [未知池模型忽略对手和死墙位置] → 输入不偷看，输出明确模型假设；概率仅作受限比较，活墙长度限制可用前瞻。
- [重复分解、财神重复利用或可见数双扣] → 分解材料守恒及逐摸 vis 递增的差分/性质测试。
- [新增特征与 U1 相关、权重过拟合] → 小网格、消融、独立种子、固定对手；无证据时保持 legacy 默认。
- [评价时间占用窗口] → 完整层级回退、节点/时钟预算、并发延迟与线上逐窗证据双重闸门。
- [同房十场线程串用缓存/解释] → 不可变上下文、完整缓存键、局部结果关联与有界缓存。
- [策略变更影响 teacher 和 RL 对手] → 显式版本指纹，发布时记录分布变化；不隐式启动数据重制或重训。
- [C/D 的遗留执行问题干扰策略验收] → 单独记录归因，沿既有协议/调度变更处理，不扩大本次代码修复范围。

## Migration Plan

1. 冻结当前 legacy 行为和运行环境，固化最小牌例与证据分类。
2. 接入共享评价、分解、有限前瞻和解释，新增显式 profile，默认仍为 legacy。
3. 完成测试、校准、独立成对评估和性能闸门，冻结 shape-v1 参数及指纹。
4. 按冻结配置做新房验收；未过任何发布闸门则维持 legacy 并交付失败证据，不将实现任务标记为已验收。
5. 所有闸门满足后单独切默认到 shape-v1，保留 `--bot-evaluator legacy` 回退；该开关不改变限速、请求或动作授权。

## Open Questions

- 最佳权重、分档收益及热点是否需要 Rust 是预先定义的实现期实验，不要求用户凭直觉选常数；实验不支持时不启用新默认。
- A/B/E 已按牌面、decision id 和 seq 定位，表中门户步号保留用户引用；D 的“49 步”与 seq=473 的映射仍未确认，不影响该牌面与超时代打事实的 fixture。
- 真实对手出牌分布及吃碰带来的回合速度模型尚无校准证据，本版记录限制，后续可在独立变更中建模。
- snapshot-only 窗口身份依赖 `window-identity-protocol` 的协议事实；本方案不承诺使历史 C 窗口获得强身份或改变当前授权规则。

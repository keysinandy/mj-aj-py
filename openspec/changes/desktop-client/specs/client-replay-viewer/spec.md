# Spec Delta

## Purpose

定义统一回放查看器的行为:浏览本地与线上对局记录、时间线步进与进度条拖动、按记录来源区分的信息完备度视角,以及与既有重放对账工具的一致性约束。

## ADDED Requirements

### Requirement: 记录浏览
客户端SHALL列出可回放的记录来源:本地批次对局(按批次/单局)与线上对局日志(按日期/会话/gid),并支持打开任意一条进入回放;记录索引SHALL与磁盘上的既有记录目录兼容,不迁移、不改名既有文件。

#### Scenario: 打开线上对局
- **WHEN** 用户在记录浏览器中按 gid 找到一场线上对局并打开
- **THEN** 回放查看器加载该记录并显示局数、座位与终局信息

#### Scenario: 打开本地批次单局
- **WHEN** 用户展开某本地批次并选择其中一局
- **THEN** 回放查看器以全知模式加载该局

### Requirement: 步进与进度条
回放SHALL支持逐步前进与逐步后退,以及进度条拖动定位到任意步;每一步SHALL展示该时刻的手牌、四家牌河、四家副露、剩余墙数与轮次;步进与拖动的响应SHALL在人类可感知的即时范围内(预计算帧或等效机制)。

#### Scenario: 前进一步
- **WHEN** 用户点击"下一步"
- **THEN** 牌面状态推进一个动作/事件,时间线高亮对应条目

#### Scenario: 后退一步
- **WHEN** 用户在非起点点击"上一步"
- **THEN** 牌面状态回退到前一状态,与顺序推进到该步的结果一致

#### Scenario: 拖动定位
- **WHEN** 用户将进度条拖到中段任意位置
- **THEN** 牌面状态等于从头顺序推进到该步的状态,无中间残影

### Requirement: 信息完备度视角
本地批次记录SHALL以全知视角回放:四家暗手可见、可切换观察座位;线上记录SHALL以自家视角回放:他家暗手不可见,仅展示公共信息与自家手牌。视角规则由记录来源决定,不可切换绕过。

#### Scenario: 本地全知
- **WHEN** 回放本地批次对局并切换观察座位到对手
- **THEN** 显示该对手的暗手与其决策

#### Scenario: 线上自家视角
- **WHEN** 回放线上对局记录
- **THEN** 他家暗手区域显示为未知,任何操作都不能显示其内容

### Requirement: 时间线内容
时间线SHALL呈现记录中的结构化条目:事件、决策(合法集、所选动作、耗时、回退原因)、动作提交(结果码)、错失吃碰杠(claim_miss)等;线上记录因协议固有的序号跳段导致的信息缺失SHALL被容忍并在时间线上标注,MUST NOT伪造缺失期间的事件。

#### Scenario: 决策条目完整
- **WHEN** 时间线滚动到某决策条目
- **THEN** 显示该决策的合法动作集、所选动作、耗时,若发生回退则显示回退原因

#### Scenario: 跳段标注
- **WHEN** 线上记录存在事件序号跳段
- **THEN** 时间线在跳段处显示缺口标注,重放状态以最近的权威锚点继续

### Requirement: 重放一致性
本地记录的重放SHALL与记录中的动作序列逐动作一致,任何一步出现非法动作SHALL显式报错而非静默纠正;线上记录的重放状态重建SHALL与既有自记日志重放工具(Mirror 语义)同源,MUST NOT引入第二套合法性判定口径。

#### Scenario: 本地重放无非法动作
- **WHEN** 完整回放一条本地对局记录
- **THEN** 每一步动作在当时均为合法动作,无静默替换

#### Scenario: 线上合法集同源
- **WHEN** 线上回放到达某决策点
- **THEN** 重建的合法动作集与该决策点记录的合法集一致

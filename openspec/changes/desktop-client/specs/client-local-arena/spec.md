# Spec Delta

## Purpose

定义本地批量对局竞技场的行为:策略与回退预算配置、座位庄家轮转、随机 BOT 规则、确定性对局记录与种子库,使本地评估可复现、可回放、可对账。

## ADDED Requirements

### Requirement: 对局策略配置
本地对局SHALL支持配置 1 个主位策略与 3 个对手位策略。主位可选 policy / BOT / policy-v3;对手位可选随机 BOT / legacy BOT / policy。BOT 策略SHALL暴露回退窗口设置,取值为 {永不回退, 10ms, 50ms, 36ms(默认)} 或任意手填的非负毫秒数;"永不回退"表示时间预算与节点预算均不设限。policy-v3 SHALL暴露置信度阈值高级项(默认 0 即关闭)。非法取值(负数、非数值)SHALL被拒绝。

#### Scenario: 主位 BOT 带回退窗口
- **WHEN** 用户配置主位为 BOT(shape-v2 评价器)且回退窗口 10ms 并开一局
- **THEN** 该局记录中主位决策的预算上限为 10ms,超时决策标注 legacy 回退

#### Scenario: 永不回退
- **WHEN** 用户配置回退窗口为"永不回退"
- **THEN** 评价器决策不受任何时间/节点预算约束,整局不发生预算回退

#### Scenario: 手填自定义窗口
- **WHEN** 用户在回退窗口输入 25(ms)并保存
- **THEN** 配置生效且负数或非数值输入被拒绝

#### Scenario: 对手位独立配置
- **WHEN** 用户将三位对手分别配置为随机 / legacy / policy
- **THEN** 对局按三个座位各自的策略执行,记录中座位策略配置逐座保留

### Requirement: 批量对局执行
本地对局SHALL支持配置总局数 N 与并发数 X(1 ≤ X ≤ 机器合理上限),第 i 局使用种子 seed0+i,与并发调度顺序无关;相同配置重跑批次SHALL逐局复现。执行中SHALL呈现进度(完成数、速率、预计剩余),且可随时取消;取消后已完成的对局记录SHALL保留。

#### Scenario: 批量完成与统计
- **WHEN** 用户配置 N=16、X=4 并运行至结束
- **THEN** 16 局全部完成,聚合统计与逐局结果一致

#### Scenario: 确定性与并发无关
- **WHEN** 同一配置(含 seed0)分别以 X=1 与 X=4 各跑一批
- **THEN** 两批对应编号的对局逐动作一致

#### Scenario: 中途取消
- **WHEN** 批量进行中用户点击取消
- **THEN** 运行停止于局边界,已完成局可回放,统计仅计已完成局

### Requirement: 座位与庄家轮转
批量对局SHALL按公平口径轮转:第 i 局主位坐 i%4 座位,庄家为 (i//4)%4,三位对手的相对顺序保持不变。N 为 16 的倍数时,(座位, 庄家) 16 种组合SHALL恰好均衡。

#### Scenario: 16 局均衡
- **WHEN** 运行 N=16 的批次
- **THEN** 主位历经 4 个座位 × 4 个庄家位共 16 种组合各一局

### Requirement: 随机 BOT 行为
随机 BOT SHALL按以下规则决策:胡合法时必胡;反应窗内优先级为 碰 > 杠 > 吃 > 过;存在多种吃法时随机取一;弃牌阶段随机选择合法弃牌。给定游戏状态与随机种子,其行为SHALL可复现。

#### Scenario: 优先级碰高于吃
- **WHEN** 某弃牌对随机 BOT 同时合法可碰与可吃
- **THEN** 随机 BOT 选择碰

#### Scenario: 有胡必胡
- **WHEN** 随机 BOT 的胡动作合法
- **THEN** 随机 BOT 选择胡

#### Scenario: 随机可复现
- **WHEN** 以相同种子重放含随机 BOT 的对局
- **THEN** 其每一步选择与原对局一致

### Requirement: 对局记录格式
每局对局SHALL落盘一条记录,内容包含种子、庄家、财神开关、base、逐座位策略配置(含回退窗口等参数)、按序动作序列与结果;该记录SHALL足以在不含 torch 的环境中逐动作确定性重放。批次SHALL另存汇总(配置、逐局索引、聚合统计)。

#### Scenario: 跨机器重放一致
- **WHEN** 将对局记录复制到另一台机器并在回放器中打开
- **THEN** 重放与原对局逐动作、逐结算一致

#### Scenario: 汇总与逐局对账
- **WHEN** 读取批次汇总统计与逐局记录
- **THEN** 胜场、积分、倍率分布可由逐局结果精确重算

### Requirement: 种子库
客户端SHALL提供种子库:种子可命名保存、列表浏览、删除;开一局或一批时可选随机新种子或从库选用;批次运行的种子SHALL可一键入库。

#### Scenario: 选用已存种子
- **WHEN** 用户从种子库选择种子并开一局
- **THEN** 该局使用所选种子,配置面板显示该种子

#### Scenario: 批次种子入库
- **WHEN** 批量对局结束后用户点击"种子入库"
- **THEN** 批次全部种子进入种子库并可在后续对局中选用

### Requirement: 聚合统计
批量对局SHALL输出主位视角统计:胜率、平均得分、流局数、倍率分布,并可展开查看逐局;统计口径SHALL与既有公平对弈评估一致(座位×庄家均衡下主位视角)。

#### Scenario: 统计等于逐局求和
- **WHEN** 批次完成后查看聚合统计
- **THEN** 各数字等于逐局记录按主位视角求和/计数的结果

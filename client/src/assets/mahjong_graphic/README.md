# Mahjong graphic assets

The 34 face-up tile SVGs in this directory are copied from
[`lietxia/mahjong_graphic`](https://github.com/lietxia/mahjong_graphic),
under `Vectors 矢量图/SVG`.

They are bundled locally so the Tauri replay viewer remains readable when it
is running without network access. See [`LICENSE`](./LICENSE) for the source
repository's license text.
